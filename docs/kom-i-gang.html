Workshop i KI-geriljaen

Kom i gang med Familietavla

Fra lenken til repoet til en app som kjører på din egen maskin. Det tar rundt ti minutter. Velg Mac eller PC under, så viser siden bare det som gjelder deg.

Du ser nå oppskriften for Mac.

1
Første gang

Installer to programmer

Node.js kjører appen, og Git henter prosjektet. Velg versjon 22 eller nyere av Node.

Mac

Last ned Node.js fra nodejs.org og installer som vanlig. Git trenger du ikke laste ned. Mac tilbyr å installere det første gang det trengs, og da trykker du bare «Installer».

PC

Last ned Node.js fra nodejs.org og Git fra git-scm.com. Installer begge som vanlig, og godta forslagene underveis.

2

Åpne terminalen

Terminalen er et vindu der du skriver kommandoer og trykker Enter. Alt under skrives der.

Mac

Trykk Cmd og mellomrom, skriv Terminal og trykk Enter.

PC

Trykk på Windows-tasten, skriv PowerShell og trykk Enter.

Sjekk at Node virker:

node -v

Du skal se v22.13 eller høyere. Står det noe lavere, installer Node på nytt.

3

Last ned prosjektet

Dette lager en ny mappe som heter familietavla, der terminalen står akkurat nå. Mac og PC bruker samme kommando.

git clone https://github.com/hodneirik/familietavla-workshop familietavla
4

Gå inn i mappen

cd betyr «gå inn i». Alle kommandoene som kommer etter dette må kjøres herfra.

cd familietavla

Står du fast senere? Sjekk hvilken mappe du er i. På Mac skriver du ls, på PC dir. Du skal se filene README.md og package.json. Ellers har du glemt dette steget.

5

Installer det appen trenger

Det tar et minutt eller to, og det kommer mye tekst. Det er normalt.

npm install
PC

Får du feilmeldingen om at kjøring av skript er deaktivert, åpne Ledetekst (skriv «cmd» i startmenyen) i stedet for PowerShell. Gå inn i mappen på nytt med cd familietavla, og bruk de samme kommandoene.

6

Lag innstillingsfilen

Du kopierer en ferdig mal, og trenger ikke endre noe i den. Her er kommandoen ulik på Mac og PC.

Mac
cp .env.example .env
PC
copy .env.example .env
7

Lag demofamilien

Dette fyller appen med en oppdiktet familie, slik at du har noe å prøve.

npm run seed:demo

Du får beskjed om at Anita, Elias, Nelly og Farmor er laget.

8

Start appen

La terminalvinduet stå åpent. Appen kjører så lenge vinduet er åpent.

npm run dev
9

Åpne appen og logg inn

Skriv denne adressen i nettleseren:

http://localhost:5173
Bruker Rolle PIN
Anita forelder 1111
Elias barn 2222
Nelly barn 3333
Farmor besteforelder 4444

Start med Anita. Det er en oppdiktet familie, så ingenting du gjør kan skade noe.

10

Sjekk at alt er på plass

Åpne et nytt terminalvindu (la det første stå), gå inn i mappen igjen og kjør testene.

cd familietavla
npm test

Går alt grønt, er du klar for workshopen.

Vil du stoppe appen, trykker du Ctrl og C i vinduet der den kjører. Det gjelder både Mac og PC.

Appen er en lokal demo med oppdiktede brukere. Du trenger ingen API-nøkkel og ingen konto.
